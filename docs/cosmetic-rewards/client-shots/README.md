# In-game gallery shots

Real ClassicUO client screenshots (client 7.0.117.0, the shard's own distribution) of every catalog item standing on the ground in Felucca, at native client scale, taken on a disposable test server. Each item is labelled with the number part of its id: the label `014` on a `FIG-01` page is `CR-FIG-014`, and on a `CN-NEC-01` page it is `CN-NEC-014`. What the pictures show is exactly what a player would see: Felucca runs the Desolation season, so leaf tiles are hidden (see the Felucca note in the catalog). Wall pieces are shown standing on the ground, not on a wall, and tiny items sit on a grey carpet pad so they can be seen.

Part 1 is the main (era) catalog, part 2 the era-neutral section (`CN-` pages), part 3 the gold-sink showroom (`GS-` pages: the 100 decorations of Design Proposal 3, labelled with their showroom number, not the id number).

Regenerate: `galleries.py plan` (add `--neutral` for part 2), then `Run-GalleryShots.ps1` (disposable host with `DecorProbe`, camera character in the real client), then `galleries.py index`.
