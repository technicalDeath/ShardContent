# Audit: Thieves skill pages (`thieves.skills.json`)

Auditor pass of 2026-10-11 over the 8 pages Hiding, Stealth, Stealing, Snooping, Lockpicking, RemoveTrap, DetectHidden, Begging. File fixed in place (valid JSON, ASCII only, no banned words, every page keeps `stats` and `gain` blocks, 5 to 8 headings, 2,100 to 4,100 characters of own text; every `requires` is a real flag and is ON in both source and deployed `shard-rules.json`).

Path shorthand: `UOC/` = `ModernUO/Projects/UOContent/`, `SRV/` = `ModernUO/Projects/Server/`, `BR/` = `ShardContent/src/BritanniaRenaissance.Content/`.

Method note: the message texts the player sees come from the client cliloc file, which is BWT-compressed. I ported `SRV/Client/BwtDecompress.cs` to Python and decoded `UOData/Cliloc.enu` (124,000 entries) to check every quoted message. The C# comments next to the calls are not reliable (example below: Hiding failure). `ShardContent/data/client/Clilocs.txt` overrides none of the numbers used here.

## Coordinator decisions applied

1. **Stats / bonus talk.** The page text never discusses stat leaning or bonus; I added none. Where a sentence only held because of a stat bonus (see Snooping and Lockpicking rows) I removed the clause instead of explaining it.
2. **No Thieves' Guildmaster: verified, section cut down.** `ModernUO/Distribution/Data/Spawns/shared/felucca/Vendors.json` has exactly one `ThiefGuildmaster`, at 2659,2194 (Buccaneer's Den). Inside Britain (x 1280-1750, y 1400-1900) that file has 58 spawners, none of them a ThiefGuildmaster, Thief, Tinker, Ranger or RangerGuildmaster (the only Tinker-family entry there is one TinkerGuildmaster at 1422,1654). The generated world is the same: `Distribution/Data/BritanniaRenaissance/Alpha2b/Spawns/Vendors.json` (57 spawners, x 1296-1650, y 1525-1826), `TownsPeople.json` (7), `britain-vendor-overrides.json` (2) contain no ThiefGuildmaster; `world-generation.json` keeps only `Vendors.json` and `TownsPeople.json` inside Britain. `ThievesGuild` membership is set only by `UOC/Mobiles/Vendors/NPC/Guildmasters/ThiefGuildmaster.cs` (grep of ShardContent and ModernUO finds no other writer). The section now reads: "The skill lets only a member of the Thieves' Guild steal from another player, and this world has no Thieves' Guildmaster, so players have no way to join. You cannot steal from other players here." The five gated paragraphs are listed verbatim below under OWNER 1.
3. **Tinker NPC.** Only a `TinkerGuildmaster` is spawned in Britain (1422,1654); no `Tinker`. No page tells the player to buy anything from a Tinker. Lockpicks: the Provisioner (2 spawned in Britain) sells them (`UOC/Mobiles/Vendors/SBInfo/SBProvisioner.cs:39`, 12 gold, stock 20; buys back 6 at :123). I changed "A tinker makes one" to "A character with Tinkering can make one" (`UOC/Engines/Craft/DefTinkering.cs:263`, 45.0 to 95.0, 1 iron ingot, in the Tools menu `UOC/Engines/Craft/T2A/TinkeringMenu.cs:33-40`). The Remove Trap page's "tinker" now says it means a character with the Tinkering skill. Nothing sells Tinker's Tools in this world (only `SBTinker` lists them, and guildmasters sell nothing: `BaseGuildmaster.IsActiveVendor => false`), so the pages do not say where to buy them.
4. **Gated paragraphs kept:** Stealing: `SafeWorld` ("any player may attack a criminal") and `KnockedOut` (a criminal who is brought down dies); Snooping: `SafeWorld`, `HotZones`, `KnockedOut`; Lockpicking: `ActionAutoRepeat`. All five flags are true in `ShardContent/data/configuration/shard-rules.json` and in the deployed `ModernUO/Distribution/Configuration/shard-rules.json` (they differ only in `helpGumps`). Rules checked in code, see rows below.

3. **Detecting Hidden delay.** The UOR callback returns 1 second but the target handler then sets the next-use time to "now" (`DetectHidden.cs:262-265`), so there is no wait after choosing a spot. `docs/Alpha-3-Player-Skill-Audit.md` SK-007 still lists this as open ("reconcile ... against the one-second historical contract"). The Hiding and Detecting Hidden pages describe it because it is live; if it is later turned off, those two paragraphs must go.

The generated stats block describes the bonus, so I left the text alone, but a player at trained 5 sees a higher number and may think "below 10.0" does not apply.
