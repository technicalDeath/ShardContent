# Lore skill pages: audit

File audited and edited in place: `parts/lore.skills.json` (8 pages: ItemID, ArmsLore, TasteID, Forensics, Musicianship, Peacemaking, Provocation, Discordance). Notes file used only as a map. JSON parses; ASCII only; no banned words; every page keeps `stats` + `gain` blocks, 5 to 7 headings and 2,461 to 4,620 characters of own text (all above the 3 headings / 900 characters minimum).

Coordinator decisions applied: (1) numeric creature-difficulty examples removed, the rule kept in words; (2) no text talks about the player's stats leaning or bonus (grep finds only "stats and skills" meaning the creature's, on Discordance); (3) the `SafeWorld` Peacemaking paragraph kept after verifying gate and rule; (4) Discordance checked against the code as shipped.

## Counts

- Sentences checked: 259 (heuristic split of own text, headings and generated blocks excluded), about 400 individual claims (numbers, message texts, ranges, prices, places, flags).
- Wrong, fixed: 9 edits.
- True but misleading, fixed: 3 edits.
- Removed as unsupported (decision 1: example numbers derived from creature-stat midpoints, not exact): 8 edits.
- Left alone (verified): the other 235 sentences. After the edits the pages hold 253 sentences.

## Verified and left alone (highlights)

- Skill window button: `StandardSkillsGump.cs:794-803`; client `skills.mul` action flag is 1 for Item ID, Arms Lore, Peacemaking, Discordance, Forensic, Provocation, Taste ID and 0 for Musicianship (checked in `UOData/skills.mul`, which also names skill 15 "Discordance", so no Enticement mismatch in the client). Server answers for Musicianship: `Skills.cs:809`.
- ItemID: range 8 plus line of sight, nonlocal and player-vendor allowed, 1 s wait, chance skill/100, label words and their order, `Identified` only changes the label, wands excepted (see below). Arms Lore: range 2, condition steps (int of hp/max*10, 0..9), damage classes ceil(min(avg,30)/5), the four example weapons (dagger 3-15, long sword 5-33, bow 9-41, halberd 5-49), armor classes ceil(min(rating,35)/5), base ratings 13/16/22/28/40, half rating at no durability. Taste ID: all messages, range 2, food versus potion/keg/person, apple/muffin/bread prices and sellers. Forensics: 10 tiles, 40.0 floor on living targets, corpse chance skill/100, killer = latest combat time, looters list, first-reader line.
- Bard skills: range 8 + int(skill/15); chances (self-calm Musicianship/100 x skill/120; windows difficulty-35..+15 for Peacemaking and Discordance, average-30..+20 for Provocation); calm time 100 - (D-10)/1.5 clamped 10..120; damage wakes with chance (HitsMax - Hits) x 0.001; waits 5/10 s (Peacemaking, Provocation reversed: 10 after success, 5 after failure), 12 s Discordance; Discordance effect int(skill/-5) percent on Str/Dex/Int and every skill with a value, no resistances under UOR, 15 s grace, 1.25 s checks, one song per creature.
- Instruments: 350 to 450 uses (`Core.UOR`), 6 s double-click gate, `CheckMusicianship` (skill/100) with a gain roll of 0 to 120, prices 21 gold, weights 1/4/5/10 (harp 35), harp not sold, exceptional lowers difficulty by 5, carpentry recipes need Musicianship 45.0 (`DefCarpentry.cs:404-420`), starter instrument per skill (`CharacterCreation.cs:833-846`), Bard template 50/50/20 (`ShardContent/data/professions/Prof.txt`). Shops: sign "Lord British's Conservatory of Music" at 1454,1561,30 next to the bard spawner 1455,1557,30; "The Saw Horse" at 1433,1600,20 next to the carpenter spawner 1430,1597,20 (`signs.cfg`, cliloc 1016163 / 1016353).
- Trainers (all skill ranges read from the NPC constructors; lesson = third of the NPC skill, minimum NPC skill 60.0): jeweler 64-100, armorer/weaponsmith 64-100, alchemist 65-88, cook 75-98, herbalist 80-100, healer Forensics 80-100, bard Musicianship 64-100 / Peacemaking 65-88 / Provocation 60-83 / Discordance 64-100, bard guildmaster 80-100 each. - Peacemaking `SafeWorld` paragraph: `SafeWorld` is a real gate (`DeferredFeatureFlags`) and is on in `shard-rules.json`; `PvpIntentService.AllowHarmful` (`PvpIntentService.cs:355-441`) decides `CanBeHarmful` for players, and both the self-song loop and the single-target path use `CanBeHarmful` (`Peacemaking.cs:107,142`), so "affected only when you could lawfully attack them" and "You cannot calm that!" hold. Knocked-out players are never harmable (same method). Kept.
- Anti-macro is disabled (`antimacro.json` `Enabled: false`); the text never mentions it; "same corpse over and over" and "one weapon takes you from 0 to the top" are consistent with it.
- Gain/training claims: every check calls `SkillCheck.CheckSkill`; unconditional gain below 10.0, minimum gain chance 1 percent otherwise (`SkillCheck.cs:130-171`); the class multipliers sit in `shard-rules.json` and are printed by the `gain` block, so none are retyped in text.

## For the coordinator (not owner decisions)

- The Welcome guide trainer list (`WelcomeGuide.GettingStarted.cs:196-203`) omits Jeweler (teaches Item Identification) although the code lets jewelers teach it; the ItemID page says jewelers teach it and is right. Guildmasters teach too (merchant, miner, warrior, bard...), only the bard guildmaster is named on the bard pages.
- The generated `stats` block was not examined beyond `HelpGenerators.StatsText`; it now handles skills with no scale ("Your stats do not change how well this skill works." / "Using it does not raise any stat."), as decided. For ItemID, ArmsLore, TasteID, Forensics, Musicianship and Peacemaking all scales are 0 (`Distribution/Data/skills.json`); Provocation and Discordance have a small scale (about 5 points at skill 0 with 100 Dex and Int), which the block describes.
