# Audit: area R item topics (r.items.json)

Auditor pass, 2026-10-11. File fixed in place (valid JSON, ASCII only, titles <= 18, <= 4 links, no class name repeated inside this file or across the other `parts/*.items.json` files, no banned words). Nothing else was touched.

UOC = `ModernUO/Projects/UOContent`. Vendor presence was checked against the live world data `ModernUO/Distribution/Data/BritanniaRenaissance/Alpha2b/Spawns/Vendors.json` (57 spawners, all in Britain, produced by `Prepare-Alpha2bWorldData.ps1` from `Data/Spawns/shared/felucca/Vendors.json` with excluded types removed; the shared file also has Barkeeper, BrideGroom and CustomHairstylist, none of which the text names) plus `britain-vendor-overrides.json` (Alchemist, Herbalist, Mage, MageGuildmaster only). Spawned in Britain and used by the text: Blacksmith, Carpenter, Furtrader, Tanner, Tailor, Weaver, Bowyer, Jeweler, Provisioner, Fisherman, Butcher, Baker, Cook, InnKeeper, TavernKeeper, Waiter, Banker. Not spawned (and not named by the text as sellers): Tinker (TinkerGuildmaster only), Miner (MinerGuildmaster only), Farmer, Rancher, Ranger, Vagabond, Beekeeper, Miller, Glassblower, StoneCrafter. Every "sells / buys" line was checked against its SBInfo for the right item, price and direction (BuyInfo = vendor sells to the player, SellInfo = vendor buys from the player; `GenericSellInfo.IsInList` is an exact-type match, `Mobiles/Vendors/GenericSell.cs:163`; `GetPriceScalar` leaves stock prices unscaled).

## Counts

- Topics: 31. Body paragraphs: 114. Sentences checked: 256. Individual claims (numbers, weights, prices, recipes, locations, mechanics) checked against code or data: about 420.
- Wrong or misleading, fixed: 9 sentences (looms x2, wool spin, tinker menu label, karma numbers, bank check minimum, Food fallback, hides with sewing kit, cotton location).
- Removed as unsupported, out of era or unobtainable: 3 (cow milking, cheese-wheel recipe line, eggs in the Raw food text) plus 1 reworded without a promise (baking).
- Qualified so fallback topics stay true for every inheriting class: 3 (ordinary logs, ordinary boards, plain leather) plus the Food fallback above.
- Left alone: the remaining sentences (about 235). Every number in them matched the code.

## Coordinator items

CookableFood: all subclasses cook by the same double-click-and-heat-source path, text made generic. BaseBeverage (also Endless Decanter, Harvest Wine, Admiral's Rum, Murky Milk): the shared claims (holds 5, drink by targeting yourself, poison, drunk, buy list) hold for them; no change. 2. **Vendors.** No Tinker, Miner, Farmer, Rancher, Ranger, Vagabond, Beekeeper, Miller, Glassblower or StoneCrafter is named as a seller anywhere. "A tinker makes ..." always means the player skill.
3. **Colored hides and leather.** Verified and kept: `TailoringMenu.TrySelectResource` accepts only `Items.Leather or Hides` (T2A/TailoringMenu.cs:337); SpinedLeather/HornedLeather/BarbedLeather derive from BaseLeather, not Leather (Leathers.cs:93); the other target answer is "That is not a valid resource" (:371); t2aCraftMenus is on (expansion.json UOTD false, ExpansionConfiguration.cs:15, no override); vendors buy exact types only. The statement in Hides and Leather is exact. Baking: see r-flour. Gold: verified, kept (see r-gold). Body parts karma: dropped (see r-body-parts).
4. **Hunger and thirst.** Nothing but Food.cs, FoodDecay.cs, CharacterCreation.cs and Beverage.cs:626 touches Hunger or Thirst; `Mobile.OnHungerChanged`/`OnThirstChanged` are empty (Mobile.cs:3838-3848); no ShardContent file reads either. 5. **Weights, stacks, prices.** All matched: ore piles 2/7/7/12 (tiledata.mul 0x19B7/0x19B8/0x19BA/0x19B9, parsed), ingot 0.1, log 2, board 1 (tiledata), hide 5, leather 1, cloth/uncut 0.1, bolt 5, cotton 4, flax 1, wool 4, thread/yarn 1, feather/shaft/gem 0.1, gears/springs/hinge/axle/axle gears 1, clock parts 1, clock frame and sextant parts 2, barrel staves 1, lid 2, hoops 5, tap 1, torso 2, gold 0.02, fish 1, kindling 5, pitcher 2 (not stated), bowls and fill values (Food.cs, Fruits.cs, Vegetables.cs, Bowls.cs).
