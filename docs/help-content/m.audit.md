# Audit: parts/m.items.json (area M, miscellaneous; 17 topics)

Independent pass on the writer's 17 item topics. Every number and claim was re-read in the code that runs (UOR: `Core.AOS`, `Core.SE`, `Core.ML` all false, T2A craft menus, old guild system, old vendor and house rules). Vendor presence was checked in `Distribution/Data/Spawns/shared/felucca/Vendors.json` and the generated `BritanniaRenaissance/Alpha2b/Spawns/Vendors.json` inside Britain bounds (x 1280-1750, y 1400-1900; both files agree), and `britain-vendor-overrides.json` (it only adds Herbalist, Alchemist, Mage and MageGuildmaster spawners, nothing used here). The file was edited in place; it parses, is ASCII only, has no banned words, every title is 18 characters or fewer, every topic has 4 or fewer links, every `related` key exists, no class name or key appears twice in any `parts/*.items.json`.

## Counts

- Checked: 17 topics, about 212 sentences after edits, about 330 individual facts (every number, price, vendor, skill figure, formula, command phrase, flag gate).
- Wrong and fixed: 2 (INFO page described as "items you have locked down"; "sand" listed as a commodity-deed resource although sand cannot be obtained under UOR).
- Misleading and fixed: 5 (house decay "nobody visits"; carpenter "makes most" add-on deeds; secures presented as separate from lock-downs; crystals: receivers must be on too; shrunken pet "a tamed pet cannot stay" without the pack-animal exemption).
- Unsupported or era-unverifiable and removed: 3 ("in front of its door"; barkeeper "tells the latest news"; dragon-prow ships).
- Imprecise and corrected: 1 (Lost Lands "far east" is the south-east).
- Left alone: everything else (all other numbers matched the code exactly).
