Independent audit against the code that runs (`Core.Expansion = UOR`), 2026-10-11. All paths are relative to the workspace root. The part file was edited in place; it parses, is ASCII only, has 37 topics, 37 unique keys, no duplicate type names across all `parts/*.items.json`, titles of 18 characters or fewer, at most 4 links per topic, every `related` key exists (`potion-keg` is in `ShardContent/data/help/items.json`), and every `requires` is a `DeferredFeatureFlags` name that is true in `shard-rules.json` (HarvestAutoRepeat, ActionAutoRepeat, Alpha3StarterScissors, Alpha3StarterBag, CampingStarterKit, HotZoneTravelWarning). ## The craft flow (coordinator point 3)

Verified in `Items/Skill Items/Tools/BaseTool.cs:149-175` and `Engines/Craft/T2A/T2ACraftToolTarget.cs`: double-click needs the tool in the pack or worn (else "That must be in your pack"), then a cursor with "Target this tool to make last item, or any other target to begin crafting"; clicking the tool repeats the last item (or says nothing was made yet and opens the menu); clicking a valid material opens the menu (`T2ACraftSystem.ShowMenu`). Blacksmithing refuses to show the cursor unless an anvil and a forge are within 2 tiles (`DefBlacksmithy.cs:CanCraft`, range 2). Tinkering takes ingots (full category list), logs (wooden items only) or a keg (potion keg) (`TinkeringMenu.cs:403-455`); Tailoring takes cloth/uncut cloth/leather/hides, not bolts (`TailoringMenu.cs:324,337`); Carpentry logs/boards; Bowcraft logs/boards/feathers/shafts. Every tool topic now says this.

**Pens (`MapmakersPen`, `ScribesPen`): the writer is right that the pen is not needed.** `DefCartography.RequiresTool` and `DefInscription.RequiresTool` are `!T2ACraftSystem.Enabled` (false here, `DefCartography.cs:24`, `DefInscription.cs:43`); `Cartography.OnUse` opens the map menu with no tool (`Skills/Cartography.cs:22`); `Inscribe.OnUse` asks "Target the book you wish to copy or scroll you want to use", and a blank scroll then opens the Inscription menu with no tool (`Skills/Inscribe.cs:25,110`). Side effect, added to the text: with the pen the menus pass the pen as the tool, so every attempt wears it (`CraftItem.cs:1411,1611`); by the skill route the tool is null and nothing wears.
