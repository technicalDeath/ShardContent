# Audit: magic skill pages (Magery, EvalInt, Meditation, MagicResist, SpiritSpeak)

File audited and fixed in place: `work/help-gumps/parts/magic.skills.json` (parses, ASCII only, no banned words, `stats` and `gain` blocks present on all five pages).
Page sizes after the audit (own text / headings): Magery 16.7k / 19, EvalInt 2.9k / 6, Meditation 3.2k / 7, MagicResist 3.8k / 5, SpiritSpeak 1.6k / 5. Every page keeps 3+ headings and 900+ characters.

Abbreviations: UOC = `ModernUO/Projects/UOContent`, SRV = `ModernUO/Projects/Server`, SC = `ShardContent/src/BritanniaRenaissance.Content`, CUO = `ClassicUO/src/ClassicUO.Client`.
Era check: `Expansion = UOR` (`ModernUO/Distribution/Configuration/expansion.json`, `SRV/Main.cs:324-332`): Core.T2A and Core.UOR true, Core.UOTD/LBR/AOS and later false. Every code path below is the one taken under that setting.

## Counts

- Checked: 325 sentences and spell lines (about 420 numbers and the 64 x reagent lists, 8 x mana/range headers), page by page: Magery 202, EvalInt 30, Meditation 38, MagicResist 35, SpiritSpeak 20.
- Spell reference: all 64 spell lines checked against their classes. Reagents of all 64 and the circle of each were compared by script against the `SpellInfo` of every class under `UOC/Spells/First..Eighth` (0 mismatches). Mana (`MagerySpell.cs:8`, `_manaTable`), book and scroll ranges (`MagerySpell.cs:15-17, 30-43`) for all 8 headers match. Exactly 8 spells per circle. Names: see the two client-name fixes below (CUO `Game/Data/SpellsMagery.cs` is the list the player sees).
- Edits made: 40 (rows 1-40 below; several rows cover more than one place in the text): 33 corrections of wrong or misleading text, 5 removals of unsupported text or text that repeats the generated `gain` block (rows 29, 34, 35, 39, 40), 2 neutral rewordings listed under OWNER (rows 20 and 26).
- Left alone (verified against code): roughly 285 of the 325 sentences and spell lines.

## OWNER:

1. OWNER: Mass Curse (`Sixth/MassCurse.cs:35-52`, non-AOS branch) curses every mobile within 2 tiles with no `ValidIndirectTarget` and no `CanBeHarmful` test: blue players without Intent, party, guild, pets and the caster are all hit, which bypasses the Safe World rule. The page now says only "creatures within 2 tiles of the spot". Decide whether to add a hook or accept it.
2. OWNER: Under Safe World a player may cast a harmful single-target spell at a guildmate or allied guild: `IsGuildWarOrDuel` is true when `attackerGuild == defenderGuild` or allied (`SC/PvpIntentService.cs:442-460`), not only at war. The page says only "at guild war with you" (true, but not the whole rule). Fields and area spells still skip guildmates (row 23).
3. OWNER: Hot Zones: single-target spells may hit any player in the same Hot Zone, but fields, Chain Lightning, Meteor Swarm and Earthquake still skip a blue player without Intent, because `ValidIndirectTarget` uses notoriety and a Hot Zone does not change notoriety (`PvpIntentService.ComputeNotoriety`, `SC/PvpIntentService.cs:338-352`). The Welcome guide says Hot Zone players "can attack each other freely". The page now says "aim a spell" and lists the skipped spells; confirm that is the intended rule.
4. OWNER: The MagicResist page recommends casting Mana Drain on yourself to train. The code allows a self-targeted harmful spell (`Mobile.CanBeHarmful` returns true for self, `SRV/Mobiles/Mobile.cs:8476-8479`), and it is verified in code but was not run in a live client. Decide whether to advertise it.
5. FYI (not a decision): `Poison.IncreaseLevel` returns Lethal for Lethal in UOR, so Arch Cure cures Lethal poison more surely (about 100 at Magery 100) than Cure (87). Stock behavior; the page now says "except against Lethal poison". Also Reactive Armor's reflected damage hits an archer at any range, and a fully absorbed blow still deals 1 (`BaseWeapon.cs:1954`); both now stated or harmless.
