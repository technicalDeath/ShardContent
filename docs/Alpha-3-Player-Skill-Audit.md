# Alpha 3 player skill audit

Status: **in progress; release blocker**. This is an inventory and evidence ledger, not a compliance sign-off. The roadmap requires a cited historical baseline, effective shard contract, implementation trace, automated checks, and proportionate live checks for every exposed skill. An empty evidence cell means unreviewed, not compliant.

## Baseline and exposure

- Source rules select `Expansion.UOR`, Felucca, a 700.0 total skill cap, and a 100.0 individual cap (`data/configuration/expansion.json`, `shard-rules.json`). The source Alpha 3 flags and phase acknowledgment remain off.
- `ModernUO/Projects/Server/Skills.cs::SkillName` and `ModernUO/Distribution/Data/skills.json` each define IDs 0–57. `OutgoingPlayerPackets.SendSkillsUpdate` sends the table length, so the client receives every entry. `SkillsInfo.RandomSkill` limits UOR random selection to IDs 0–48; this does **not** establish that 49–57 cannot be gained or used through other paths.
- IDs 0–48 are the pre-AoS audit cohort. Runtime ID 15 is named Discordance in the client table while retaining `ProfessionSkillName: Enticement`; the owner is reviewing which historical behavior to target. Under the April 2000 UOR baseline it is Enticement (peacefully drawing a creature/NPC toward the player); the [official Publish 16 notes](https://uo.com/wiki/ultima-online-wiki/technical/previous-publishes/2002-2/2002-publish-16-23rd-april/) state that Publish 16 shipped April 23, 2002 and replaced it with Discordance, a bard ability that weakens creatures. Peacemaking is separate (ID 9). The [official 1999 publish notes](https://uo.com/wiki/ultima-online-wiki/technical/previous-publishes/1999-2/1999-03-24th-february/) document Stealth and Remove Trap. [Age of Shadows notes](https://uo.com/wiki/ultima-online-wiki/technical/previous-publishes/2003-2/publish-17-1-age-of-shadows/) place Necromancy, Focus, and Chivalry after the Renaissance era. The [2005 Samurai Empire notes](https://uo.com/wiki/ultima-online-wiki/technical/previous-publishes/2005-2/publish-30-2nd-february/) reference Bushido and Ninjitsu books, the [2005 Mondain's Legacy notes](https://uo.com/wiki/ultima-online-wiki/technical/previous-publishes/2005-2/publish-37-27th-october/) reference Spellweaving, and the [2009 Stygian Abyss notes](https://uo.com/wiki/ultima-online-wiki/technical/previous-publishes/2009-2/publish-60-8th-september-stygian-abyss/) identify Imbuing, Mysticism and Throwing as new skills. Later skill IDs need individual reachability checks, even though UOR random selection excludes them.
- The current [official skills index](https://uo.com/wiki/ultima-online-wiki/skills/) describes today's game and is a navigation aid only. Current skill pages cannot by themselves establish the UOR historical rules. Use dated publish notes or contemporary source for each final baseline entry.

## Shared later-era skill entry-gate evidence

The shared gate applies to each ID below; it is not a claim that each skill's spell, item, recipe, or client surface has been audited. ModernUO `SkillCheck.IsSkillAvailable` divides the IDs into contiguous expansion cohorts and guards all four public location/target check callbacks. `SkillCheck.CheckSkill` and `SkillCheck.Gain` also reject unavailable skill IDs, and `SkillsInfo.RandomSkill`, `RandomCombatSkill`, `RandomMagicSkill`, and `RandomCraftSkill` bound their selection sets by the active expansion. These are the generic entry points relevant to player checks and gain. The official publish references establish the later-era cutoff: Publish 17 is dated February 10, 2003; Publish 28 is dated January 12, 2005; Publish 37 is dated October 27, 2005; Publish 60 is dated September 8, 2009. Publish 60 explicitly labels Imbuing, Mysticism, and Throwing as new skills.
