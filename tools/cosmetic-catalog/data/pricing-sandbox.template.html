Gold-Sink Pricing Sandbox

The 100 house decorations of Design Proposal 3. Set a base price and a curve; every price, the cost of the whole set and each collection update. Nothing here is saved to the game: use the export when you have decided.

The curve

price = base x rarity multiplier x (1 - spread + 2 x spread x position), position 0 for the plainest piece of a rarity and 1 for the coolest by coolness score, never above the ceiling. Type in a price box in the table to override one piece.
